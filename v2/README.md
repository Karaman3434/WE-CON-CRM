# WEİCON CRM V2

Bu klasör mevcut CRM uygulamasından bağımsız, sıfırdan geliştirilen yeni uygulamadır.

- Mevcut `index.html` değiştirilmez.
- V2 kendi HTML/CSS/JS dosyalarıyla çalışır.
- İlk sürüm: dashboard, müşteri yönetimi, müşteri kartı, satış süreci, ürün kataloğu, görevler, ziyaret kaydı ve temel raporlama.
- Veri modeli şimdilik tarayıcı localStorage üzerinde izole tutulur.
- Firebase entegrasyonu, mevcut uygulamaya dokunmadan sonraki geliştirme aşamasında ayrı veri katmanı olarak eklenebilir.
